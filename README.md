# Portfólio — Gustavo Ferrari

Landing Page pessoal desenvolvida para apresentar meu perfil, meus conhecimentos, projetos e evolução na área de tecnologia.

## Sobre o projeto

Este projeto consiste em uma Landing Page criada como parte do meu portfólio pessoal.

A página tem como objetivo apresentar de forma simples e organizada minhas informações, conhecimentos e projetos desenvolvidos durante minha formação em tecnologia.

O projeto também serve como forma de colocar em prática conceitos de desenvolvimento web, responsividade, organização de código e controle de versão com Git e GitHub.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Objetivos do projeto

* Desenvolver uma página pessoal para meu portfólio;
* Praticar desenvolvimento Front-End;
* Aplicar conceitos de HTML, CSS e JavaScript;
* Trabalhar com design responsivo;
* Melhorar a organização e estrutura do código;
* Utilizar Git e GitHub para controle de versão;
* Apresentar minha evolução na área de tecnologia.

## Responsividade

A Landing Page foi desenvolvida pensando em diferentes tamanhos de tela, buscando proporcionar uma boa experiência em:

* Computadores

## Como executar o projeto localmente

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta do projeto

```bash
cd nome-do-repositorio
```

### 3. Execute o projeto

Abra o arquivo `index.html` em seu navegador.

Também é possível utilizar a extensão Live Server no Visual Studio Code para executar o projeto durante o desenvolvimento.
